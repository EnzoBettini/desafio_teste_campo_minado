# desafio_teste_campo_minado

## Especificação do desafio

Campo minado com tabuleiro **18×14** e **40 minas**.

A implementação deve suportar (conforme regras documentadas nos testes):

- Inicialização do tabuleiro com quantidade fixa de minas
- Revelar células, contagem de vizinhança e derrota ao acertar mina
- Condição de vitória (todas as células seguras reveladas)
- Comportamentos adicionais cobertos pela suite (ex.: bandeira, primeira jogada segura, se aplicável)

Código em `src/`; casos de teste em `tests/` (JavaScript + Jest).

## Como executar os testes

```bash
npm install
npm test
```

Modo observação:

```bash
npm run test:watch
```
